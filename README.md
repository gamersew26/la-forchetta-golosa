# la-forchetta-golosa
la forchetta golosa
Ecco la guida passo dopo passo dall'inizio, scritta in modo semplice, usando solo GitHub Desktop e GitHub Online.
Segui questi step uno alla volta:

Step 1: Prepara il tuo codice (Sul tuo PC)

1. Apri il file index.html sul tuo computer con VS Code (o il tuo editor di testo).
2. Cancella tutto il vecchio testo e incolla il codice pulito con un solo antipasto che ti ho dato nei messaggi precedenti. Salva il file.
3. Prendi la foto del tuo antipasto, nominala esattamente antipasto.png e inseriscila dentro la cartella chiamata img del tuo progetto.

Step 2: Crea il tuo ramo (Su GitHub Desktop)

1. Apri l'applicazione GitHub Desktop.
2. Guarda in alto al centro dove c'è scritto Current Branch. Cliccaci sopra.
3. Clicca sul pulsante New Branch (Nuovo Ramo).
4. Scrivi come nome menuAntipasti e clicca su Create Branch.
(In questo modo hai creato la tua stanza privata per non toccare il lavoro degli altri).

Step 3: Salva e Invia il tuo lavoro (Su GitHub Desktop)

1. Guarda in basso a sinistra su GitHub Desktop. Nel box bianco Summary, scrivi un titolo breve, ad esempio: Aggiunto antipasto.
2. Clicca sul pulsante blu in basso con scritto Commit to menuAntipasti.
3. Ora guarda in alto a destra: clicca sul pulsante Publish branch (o Push origin). Aspetta che carichi.
4. Appena ha finito, nello stesso punto apparirà un grande pulsante blu con scritto Create Pull Request. Cliccalo!

Step 4: Chiedi l'unione del sito (Su GitHub Online)

1. Cliccando quel pulsante si aprirà automaticamente il browser su GitHub Online (internet).
2. Ti troverai davanti a una pagina con un grande pulsante verde: clicca su Create pull request.
3. Clicca di nuovo sul pulsante verde di conferma Confirm.
4. La tua parte è finita! Ora di' ai tuoi 3 compagni di fare esattamente questi stessi quattro passaggi dai loro computer (ognuno con il proprio ramo, es. menuPizze, menuDessert, menuBevande).

Step 5: Il Project Manager unisce tutto (Su GitHub Online)

Questo passaggio va fatto su internet da chi gestisce il gruppo (il PM):
1. Vai sulla pagina internet di GitHub Online del vostro progetto.
2. Clicca sulla scheda Pull Requests che trovi in alto. Vedrai la lista delle richieste tue e dei tuoi compagni.
3. Clicca sulla prima richiesta (es. la tua degli Antipasti).
4. Scorri la pagina verso il basso e clicca sul pulsante verde Merge pull request.
5. Clicca su Confirm merge.
6. Torna indietro nella scheda Pull Requests e ripeti la stessa identica operazione (clicca, Merge e Confirm) per le Pizze, per i Dessert e per le Bevande.
